# 地点影像来源说明

地图点位 1–44 均有影像兜底；如果已有对应点位的影像卡片，页面会保留它。缺图时按校园入口、教学区、餐饮区、琴湖、孔子像、博物馆等类别显示校园公开照片，不再显示“地点影像待补充”。

主要影像来源是[新浪图片《带你走进沈阳理工大学》](https://photo.sina.cn/album_37_88171_570970.htm?ch=37&hd=1&vt=4)，其中校门、校内景观、航拍、志学堂、餐饮服务中心、琴湖、孔子像、兵器广场及兵器博物馆图片由学校提供。

校门照片在来源中只标注为“学校校门”，未区分北门、南门或东门。因此 40 号北门只标为校门实景参考；41 号南门、42 号东门使用校园环境参考图，不把北门照片误标成南门或东门。其他未找到该建筑单独实拍的位置也标注为区域参考图。
