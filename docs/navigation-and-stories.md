# 校园地图导航与地点科普资料

## 导航和自行车点位

- 地图选点、起点和终点选择、步行/骑行切换及路线建议由本地地图点位生成，适合本作品的校园导览演示。
- 推荐路线依据示意地图上的地点位置和校园主通道组织，路程、耗时为估算，不包含实时路况、封闭道路、无障碍通行或高德/苹果地图的道路数据。
- 地图上的自行车图标是建议核对的停放参考点（校门、图书馆、食堂一带），不是实时共享单车位置或可用车辆数量。正式发布前应现场核对校方允许停放区域。
- 南门地图点位按用户提供的校园导览图重新校正；南门图片不再引用北门照片。

## 内容标注原则

地点故事和科普卡片用于校园文化导览。能由公开来源支持的事实会附上来源；建筑内部功能、展品名称、开放时间、门禁和无障碍信息目前不完整，应以现场信息或学校提供材料补齐。地点故事在详情面板中以折叠卡片呈现：收起时突出显示主题标题，展开后显示完整介绍；兵器博物馆详情中另有兵器广场专题故事。路线面板提供地点搜索，搜索结果可直接设为起点或终点，再生成推荐路线。所有地点的影像卡片已配图；缺少单点实拍时，使用标注清楚的校园或区域参考图，不冒充具体楼宇、南门或东门近景。详细图片来源和许可见 [photo-library-attribution.md](photo-library-attribution.md)。
