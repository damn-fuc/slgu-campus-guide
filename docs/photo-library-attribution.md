# 地点影像补充与来源

## 使用方式

地图中的 44 个地点详情均提供影像卡片。能从公开来源确认对应地点的，使用该地点照片；其他建筑使用校园或区域参考照片，并在卡片中注明“参考图，不代表该建筑近景”。南门和东门只使用校园环境参考图，不复用北门照片。

## 来源与说明

- [沈阳理工大学校园图片集（新浪图片）](https://photo.sina.cn/album_37_88171_570970.htm?ch=37&hd=1&vt=4)：多张图注标注为沈阳理工大学供图，包含校门、校内风景、校园航拍、志学堂、餐饮服务中心、琴湖、孔子像、兵器广场和兵器博物馆。页面未为所有教学楼、宿舍和校门方向提供独立图注。
- [沈阳理工大学运动会报道](https://yurenhao1.sizhengwang.cn/a/sylgdx/230628/1560439.shtml)：体育活动参考图。

## 点位标注原则

- 兵器博物馆、琴湖、孔子像、兵器广场使用可确认的对应照片。校门照片只标为“校园校门实景参考”，不推定对应哪一道门。
- 教学区、宿舍区、食堂、体育区优先使用对应的校园区域或活动照片，卡片会标明图片范围，避免暗示为具体单栋建筑近景。
- 北门点位使用未标明门别的校园校门参考图；南门、东门使用校园环境参考图，不复用该校门照片。收到学校或用户提供的入口照片后再替换。
- 外部图片通过来源网站加载，展示需要联网。比赛公开展示前，请向学校确认校方供图的使用授权，并保留来源标注。
