# 《兵器寻迹：沈理工校园数字导览》实施计划

> 状态：实施中。用户已确认直接在当前项目目录修改，并要求视觉上更精致，同时借鉴两种参考作品的交互表达。

## 实施决定

- 交付形态：本地可打开的响应式静态网页，无需账号、服务器或外部地图服务。
- 技术方式：沿用现有 HTML、CSS 和 JavaScript 页面结构，在当前项目中完善交互。
- 地图方式：使用已放入 assets/maps/campus-detailed-map.png 的用户第二张详细地图作为交互底图；第一张示意图仅参考分区和路线强调方式。
- 地点数据：以详细地图的 1–44 编号为完整目录；每个地点都有地图位置、地图原名、类别和可打开的地点卡片。信息未核实的地点只使用中性描述并标记待核实。
- 路线方式：提供三条已确认的精选路线；自由模式允许用户选起点、按顺序添加重点站点、调整顺序，并可选设终点。路线线条只表达用户选定顺序，不代表真实道路导航或步行距离。
- 工作目录：直接修改当前项目。现有目录没有 Git 仓库，因此本计划不包含分支或提交步骤。

## 视觉方向

- 参考 Story Map Tour 的地图与逐站叙事、Memory Map 的地图热点与内容卡片；只借鉴体验组织，不复制代码或素材。
- 定位为“校园档案地图”：把用户提供的手绘地图作为主视觉，用清晰编号、路线顺序线和简洁的展签式信息层呈现校园内容。
- 色彩采用松针墨绿（#173B34）、地图纸白（#F3F0E6）、路线朱红（#C94B38）、叶绿（#91A66B）与旧铜金（#B58A54）。地图本身保留原色，界面以墨绿建立品牌识别，朱红只突出当前路线和选中地点。
- 首页让详细地图成为主要画面；导览页采用地图与逐站故事面板并列，并提供可切换路线的站点顺序；自由探索页组合可搜索地点清单、详情卡和自定义路线编辑。
- 中文标题使用本机可用的宋体/衬线字体，界面文字使用清晰的系统无衬线字体；避免依赖在线字体或图片。
- 动效仅用于路线选择、当前站切换和地图热点反馈；支持减少动态效果偏好。

4. 将当前单路线数据替换为三条路线对象，每条包含 id、标题、主题说明、有序地点 id 列表和逐站讲解提示：
   - 兵器文化线：40 北门 → 1 图书馆 → 44 校史馆 → 43 兵器博物馆
   - 校园人文线：41 南门 → 38 孔子像 → 14 琴湖 → 16 艺术馆 → 44 校史馆

5. 保留博物馆主题和展品演示内容，但未核实资料继续标注待确认。

**完成条件：** 数据目录完整覆盖 1–44；三条路线顺序与设计稿一致；没有把示例内容伪装成已核实事实。

## 阶段 3：首页和精选路线入口

修改 index.html、scripts/app.js、styles/main.css：

1. 将首页入口文案改为“跟我走：主题导览”和“我想自己逛”，并介绍三条路线和自定义路线。
2. 用户进入“跟我走”后先看到三张精选路线卡，显示名称、主题、站点数和站点顺序摘要。
3. 选择路线后显示该路线地图、当前站点、进度、站点列表、讲解和上一站/下一站控制。
4. 允许用户返回路线选择并切换到另一条路线。

**完成条件：** 三条路线均可单独进入，且界面能辨认当前路线和当前站点。

## 阶段 4：详细地图和全点位选择

修改 index.html、scripts/app.js、styles/main.css：

1. 用详细地图图片作为地图平面；将热点按底图相对坐标逐一定位到 1–44 号位置。
2. 重写现有 renderPins，让地图上的每个编号地点都生成独立可聚焦、可点击的热点，并在辅助地点清单中提供相同的选择入口。
3. 地点清单支持搜索和类别筛选；筛选只帮助查找，不会删除地点或限制其能否加入路线。
4. 热点被选中时打开对应地点详情；地图缩放、拖动和不同屏幕尺寸下，地图图像、热点和路线保持对齐。
5. 详细地图编号较密集处仍保留地点清单入口，确保不必精准点中重叠区域也能选到全部地点。
6. 将现有固定 SVG 路线改为按当前路线地点坐标动态连接；自由路线按用户当前顺序重绘，并标清这是顺序示意线。

**完成条件：** 1–44 每个地点都可从地图和清单打开，热点对应正确名称；地图不承诺道路级导航。

## 阶段 5：自由探索和自定义路线编辑

修改 scripts/app.js、index.html、styles/main.css：

1. 在自由探索面板中加入路线编辑区和清晰提示：先设起点，再添加重点站点。
2. 为地点详情和地点清单提供“设为起点”“加入重点站”“设为终点”操作。
3. 支持移除站点、清空路线，以及用上移/下移控制调整重点站点顺序；起点和可选终点不能重复占用中间站点。
4. 有起点后即时显示自定义路线；用户可先只设起点，之后继续添加重点站和可选终点。
5. 让地图选点和清单选点都可编辑路线；查看地点详情时保留当前路线草稿。
6. 对没有设置的路线阶段给出直观的下一步提示，不展示未经计算的距离或时间。

**完成条件：** 用户能从 44 个地点任意选起点和重点站、编辑顺序、移除或清空，也能选填终点，并在地图上看到所选顺序。

## 阶段 6：导览中自由岔出与返回

修改 scripts/app.js：

1. 导览模式下，44 个地点热点全部保持可点；点击路线外地点或展品时打开详情。
2. 保存正在浏览的路线 id 和站点序号，再从详情里的“返回导览”操作恢复到原路线、原站点和进度。
3. 地点详情在两种模式中读取同一份 content.js 数据，避免名称和内容不一致。
4. 从自由模式切回导览时保留已选择路线；首次进入时显示三条路线选择页。

**完成条件：** 任一导览站点都能岔出查看地图其他地点，并准确回到原路线位置。
