# 《兵器寻迹：沈理工校园数字导览》设计稿

## 1. 项目概述

《兵器寻迹：沈理工校园数字导览》是一款面向校内师生、访客和青少年的响应式数字传播作品。它以沈阳理工大学校园地图和兵器博物馆为主要空间，提供三条精选导览路线，也允许观众从地图上的 44 个编号地点中自行设置起点并挑选重点站点，组成自己的参观顺序。

作品的核心体验是“跟着故事走，也可以随时自己探索”。线性导览与自由探索共享同一份地点、展区和藏品内容；观众在导览中打开自由探索内容后，可以一键返回原来的导览站点和进度。

## 2. 设计目标

1. 让观众能通过三条主题路线快速了解校园地标、校园文化和兵器博物馆。
2. 让观众能在地图上的全部 44 个编号地点中自行选择起点和重点站点，按自己的顺序探索。
3. 用短文字、图片和可选音频讲清军事科技与历史文化知识，避免仅罗列展品名称。
4. 对尚未实地核实的展品名称、位置、年代和故事明确标注待核实，不将推测写成事实。
5. 形成可演示、可截图、可录屏的完整数字媒体作品原型；地图、讲解、详情和模式切换均可操作。

## 3. 目标用户与使用场景

- **首次到校访客**：从校园入口进入，选择主题路线了解校园与兵器博物馆。
- **校内师生**：在自由探索模式中查看校园地点、博物馆主题展区和精选藏品。
- **中学生及普通公众**：通过简明故事卡了解装备发展、工程技术和相关历史背景。
- **比赛评审与演示观众**：通过完整首页、交互地图、导览路线和内容详情快速理解作品价值与完成度。

## 4. 内容边界与资料原则

### 4.1 地图素材

- 用户提供的第二张沈阳理工大学手绘校园导览图已保存为 `assets/maps/campus-detailed-map.png`，作为首版可交互地图底图。图中 1–44 号地点全部纳入地点数据，并在地图上设置可点击热点；其编号和名称以原图为准，进入成品前仍需与学校实际地图核验。
- 用户提供的第一张示意地图用于参考清晰分区、重点标注和红色推荐路线的表达方式。该图明确标注为“示意图”，不把它当作真实测绘底图，也不从中推断精确道路、距离或建筑坐标。
- 热点以底图尺寸的相对位置标定，地图缩放或适配屏幕时保持与地点标记对齐。用户可以点击地点标记或地图编号打开详情；同时提供可筛选地点清单，确保小屏和热点重叠时仍可选择全部 44 个地点。
- 地图表达的是校园地点关系和作品设定路线，不承诺真实导航精度、室内定位、精确步行距离或自动路径规划。

### 4.2 博物馆内容

- 可先采用官方公开资料支持的主题分类作为展区入口，例如冷兵器、轻武器、火炮与导弹、舰船、航空航天、工程装备等；此分类参考[辽宁省人民防空办公室关于博物馆展陈的介绍](https://rfb.ln.gov.cn/rfb/rfyw/2022080517100426701/index.shtml)，最终分类以博物馆现场展陈为准。
- 具体藏品卡片优先使用用户提供的现场照片、铭牌文字和馆方确认资料。
- “东方红一号备份星”等网络报道中提及的代表藏品仅列为候选（[相关网络报道](https://www.sohu.com/a/242384358_100190439)），不在未核验展签、馆方资料或现场信息前作为确定事实发布。
- 外部文字、图片、音频、字体和代码均记录来源、授权或使用条件；比赛材料中说明自制内容与引用内容的边界。
- 无法确认的内容在原型中使用“内容待馆方核实”的清晰占位，不杜撰展品信息。

## 5. 信息架构

### 5.1 首页

- 标题：兵器寻迹
- 副标题：沈阳理工大学校园与兵器博物馆数字导览
- 两个主入口：
  - **跟我走：主题导览**
  - **我想自己逛**
- 辅助入口：作品简介、使用说明、资料来源与制作说明。

### 5.2 跟我走：三条精选路线

每条路线都有路线总览、地图顺序线、当前站点高亮、站点列表、上一站/下一站和进度提示。每站展示名称、简短讲解、知识点和图片位；资料不足时使用明确标注的占位内容。三条初版路线如下：

| 路线 | 站点顺序 | 内容侧重 |
|---|---|---|
| 兵器文化线 | 40 北门 → 1 图书馆 → 44 校史馆 → 43 兵器博物馆 | 从校园入口和学习空间进入校史，再聚焦兵器文化 |
| 校园人文线 | 41 南门 → 38 孔子像 → 14 琴湖 → 16 艺术馆 → 44 校史馆 | 校园礼序、景观、人文艺术与学校记忆 |
| 校园活力线 | 1 图书馆 → 20 学生食堂 → 15 龙翔体育场 → 18 篮球场 → 42 东门 | 学习、生活、运动与校园开放空间 |

这些路线作为作品首版的“精选路线”，依据校园地标和叙事主题编排；在没有实际客流数据前，不宣称它们是统计意义上的热门排名。选择任一路线后，用户可在路线站点间前进或后退，也可点击地图上的路线外地点查看详情，再一键返回原路线和原站点。

### 5.3 我想自己逛：自定义路线与地点探索

- 主视图：以 `assets/maps/campus-detailed-map.png` 为底图，地图上 1–44 号地点都可点击、查看和加入路线；地点清单提供同等选择能力。
- 用户可将任一地点设为起点，再从其余地点中加入一个或多个重点站点；可调整站点顺序、移除站点、清空后重选，并可选设一个终点。路线线条按用户选定顺序连接。
- 点击地点可以打开详情；详情中的“设为起点”“加入路线”或“设为终点”操作可直接用于构建路线。路线编辑状态在查看详情后保留。
- 类别筛选：校园地标、教学与办公、生活服务、体育休闲、宿舍、校门、博物馆与校史。分类是检索辅助，不限制地点能否被选择。
- 点击校园地点：显示地点简介、图片/占位和相关提示。点击 43 号兵器博物馆后，可查看馆内主题展区入口；具体展区和藏品须使用经核实的内容。
- 提供搜索或类别筛选以便快速找到地点；地图与清单均应能选择全部 44 个编号地点。

### 5.5 详情卡

每张地点、展区或藏品卡根据资料完整度展示：

- 名称、类别与所在位置/展区；
- 图片或图片占位；
- 一段易懂的概述；
- 可选的“背景故事”“原理/工艺”“相关知识”分段；
- 可选音频播放及文字稿；
- 资料来源与核实状态。

## 6. 主要交互流程

### 流程 A：快速导览

首页 → 选择“跟我走” → 选择三条精选路线之一 → 查看路线总览 → 进入第 1 站 → 阅读讲解并前进/后退 → 抵达路线终点 → 选择展区/代表藏品或完成导览。

### 流程 B：自主探索

首页 → 选择“我想自己逛” → 点击地图热点或从地点清单选择地点 → 查看详情，或将地点设为起点/加入重点站点/设为终点 → 调整站点顺序 → 查看自己的路线 → 继续探索或逐站浏览。

### 流程 C：导览途中岔出探索

导览站点地图 → 点击路线外的任一地图地点或藏品热点 → 打开自由探索详情 → 点击“返回导览” → 恢复原路线、原站点和进度。

## 7. 视觉与交互方向

- 视觉主题采用“校园导览 + 兵器科技史”融合方向：以地图、路线和展品图片为主体，使用深蓝/蓝灰建立可靠感，以红色或橙色突出路线、当前位置和重要提示。
- 不把页面做成军事游戏或武器操作模拟；重点放在历史、工程、科学传播和校园文化。
- 地图在手机竖屏下优先保证热点可点、地图可拖动；桌面端可采用地图与讲解卡并列布局。
- 关键状态需清楚：当前导览站、已浏览站点、筛选类别、返回导览入口、资料待核实提示。
- 图片缺失时展示统一的插画/色块占位和清楚标签，确保页面结构完整。

## 8. 内容数据模型

地点、展区和藏品采用统一内容结构，避免两种浏览模式出现内容不一致：

```text
id
name
type                 // campus, museum_zone, artifact
category
mapPosition          // 相对地图图片的归一化坐标，待标定
summary
storySections[]      // 标题、正文
images[]             // 文件/来源/授权信息
audio                // 文件/文字稿/来源，可为空
sources[]
verificationStatus   // confirmed, needs_review, placeholder
routeOrder           // 可为空；精选路线分别维护各自的站点顺序
```

每个精选路线单独保存名称、主题、站点顺序和讲解文案；不显示未经实测的时长。用户自定义路线保存起点、可选终点和有序重点站点。自由探索和导览从同一地点内容集合读取详情；查看路线外内容时保留路线和站点进度。

## 9. 首版范围与暂不纳入项

### 首版包含

- 首页双入口；
- 详细校园地图底图及 1–44 全部可点击、可选择地点；
- 三条各含至少 3 个地点、可前进/后退的精选导览路线；
- 自由模式下自选起点、重点站点、可选终点并调整顺序的路线编辑器；
- 地点、主题展区和精选藏品详情卡；
- 导览中打开自由内容并返回原进度；
- 图片、音频/文字稿的展示位；
- 资料来源与待核实状态标注。

### 首版暂不包含

- GPS/室内定位、实时导航或自动路线优化；
- 用户账户、评论、排行榜或后台内容管理系统；
- 未经馆方确认的完整馆藏数据库；
- 需要服务器的个性化推荐与数据分析。

## 10. 验收标准

1. 首页提供“跟我走”和“我想自己逛”两个入口。
2. 跟我走提供上文列出的三条路线；每条路线至少 3 个地点，能前进、后退并显示当前站点。
3. 自由模式中，用户能把 44 个地点中的任意地点设为起点，并将任意其他地点加入重点站点；能调整、移除、清空顺序，并可设置终点。
4. 详细地图的 1–44 号地点均可通过地图热点和地点清单打开详情及加入自定义路线。
5. 在导览途中打开路线外内容后，可以返回原路线、原站点并继续。
6. 地图热点和地点详情一一对应，窄屏和宽屏均可完成选择；重叠热点仍有清单入口可访问。
7. 未经核实的地点名称、展品、时间、数字和故事均有明确状态提示，不作为事实陈述。
8. 演示版可以从首页完整浏览任意一条精选路线，也可独立创建并查看自定义路线。

## 11. 待用户提供或确认的素材

为进入内容制作与地图标定阶段，需要逐步补充：

1. 博物馆现场照片或允许使用的馆藏/展厅图片；
2. 代表藏品名称、展签照片/文字、年代和馆方确认的简要说明；
3. 详细地图 1–44 号地点的准确名称和位置核验，尤其是原图第 12 号名称；
4. 三条路线中各站点的现场讲解素材，以及兵器广场是否作为补充地点加入地图；
5. 是否能提供讲解录音，或先采用文字讲解；
6. 参赛作品要求的最终形式（网页、互动视频、H5、程序等）和技术限制。

资料可以分批提供；没有的部分先用明确标注的演示内容占位。

## 12. 参考模式

- [Map Tour Storytelling Template JS](https://github.com/MehulChoksey/map-tour-storytelling-template-js)：参考按顺序讲述地点故事，同时允许从地图选择位置的导览组织方式。
- [Memory Map Toolkit](https://github.com/memorymapper/memorymap-toolkit)：参考以地图热点连接地点、文字、图片和音频的自由探索方式。
- [Jewish East End Memory Map](https://jewisheastendmemorymap.org/)：参考点击地图区域后打开历史内容、图片和音频的内容呈现方式。

以上仅借鉴交互与内容组织思路；项目主题、地图标注、文案、视觉和数字媒体素材需要围绕沈阳理工大学及其兵器博物馆重新创作，并明确标注第三方素材来源和授权情况。
